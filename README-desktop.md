# Windows 桌面版使用指南

适用版本：**1.0.18+desktop.7**。

助手在 Windows 中提供运行、账号、策略、设备、记录和设置六个页面。模拟器只需运行游戏。

## 安装与启动

系统要求：Windows 10 1809 或以上 / Windows 11 x64，至少 4 GB 内存，另为模拟器预留运行内存。程序自带 Java 21。

1. 下载 Windows ZIP 和同名 `.sha256` 文件，核对校验值：

   ```powershell
   Get-FileHash .\LimingjieAssistant-desktop-1.0.18+desktop.7-win-x64.zip -Algorithm SHA256
   ```

2. 将整个 `LimingjieAssistant` 文件夹解压到可写目录，例如 `D:\Tools\LimingjieAssistant`。
3. 双击 `LimingjieAssistant.exe`，按首次向导完成准备。未签名程序可能出现 SmartScreen 提示；确认下载来源和校验值后，按 Windows 提示继续。

## 连接模拟器

1. 推荐使用 MuMu 12 或雷电 9，设置为 **1920 × 1080 横屏**，开启 ADB 调试。
2. 在「设备」页点击「重新检测」，选择在线设备并连接；也可填写 `127.0.0.1:端口` 后点击「添加并连接」。MuMu 的运行端口会自动补齐，同一设备的多个地址合并显示。
3. 找不到 ADB 时，展开「高级：ADB 工具与路径」，选择模拟器自带的 `adb.exe`，或下载官方 Platform Tools。更换路径前先断开设备。
4. 等待安装信息核验、截图测速和触控准备完成，进入「设备详情」查看结果。

MaaTouch 是默认触控方式；有兼容问题时可切换为 ADB 输入并重新连接。「测试点击」用于在非游戏页面中央点击一次。

自动执行按实际截图校验 1920 × 1080；其他尺寸可用于连接、预览和只读识别。游戏内请关闭「播放角色加入动画」，运行时保持游戏在前台。

## 账号与任务

1. 在「账号」页新增账号并选择服务器。B 服填写登录账号与密码；渠道服填写 `uid` 和 `access_key`。更换服务器时重新填写凭据。
2. 在「设备」页绑定账号，再打开运行页。**绑定只选择助手使用的凭据，模拟器内的游戏账号需要自行核对。**
3. 使用「登录并读取」查看当前开局。遇到验证码时，在系统浏览器中完成；打不开浏览器时可复制验证链接。
4. 在运行页设置公会目标、计数方式、难度和常用参数，保存后开始。路线、Boss 和撤退选项位于「高级配置」。彻底撤退会放弃当前开局，启用前确认保留需求。
5. 在「策略」页编辑编组、开局阵容与个人评分。保存的策略供所有设备下一次任务使用；运行中的任务保留启动时的策略。

「只读识别」分析当前画面；「执行入口流程」与批量任务会操作游戏。批量启动时，助手会按所绑定账号的服务器关闭并重启对应游戏进程。

## 多设备与运行控制

每台设备有独立运行标签和后台进程，切换标签保留任务与编辑草稿。账号、账号配置、全局策略和汇总记录由所有设备共用；任务目标与任务选择分别保存在各设备运行页。

| 操作 | 作用 |
| --- | --- |
| F5 | 开始当前运行页任务，需先保存配置 |
| F6 | 暂停 / 继续当前画面任务 |
| F7 | 停止当前运行页任务 |
| 停止全部 | 停止所有设备任务 |
| 关闭运行标签 | 停止该设备任务并关闭会话；运行中或有草稿时提示确认 |
| 关闭主窗口 | 有任务或草稿时选择最小化、停止全部退出或取消 |

账号、策略等全局页面不处理运行快捷键。网络刷开局支持停止；画面任务另支持暂停与继续。后台标签遇到验证码时会显示提醒，切回该页处理。

同一模拟器按启动身份识别，同一账号限制并发运行。重开助手后手动连接设备；模拟器启动身份未变时可恢复配置与绑定，重启模拟器后重新确认账号。运行期间账号绑定和设备连接保持锁定。

## 数据与备份

| 位置 | 内容 |
| --- | --- |
| 程序旁的 `data` | 带 `portable.flag` 时使用的主数据目录 |
| `%LOCALAPPDATA%\LimingjieAssistant` | 移除便携标记后的默认主目录 |
| `<主数据目录名>-run-tabs` | 与主目录相邻，保存窗口状态、设备会话及各设备的任务配置与缓存 |

可用 `--data-dir <目录>` 指定主目录。同一数据目录只允许一个助手实例。凭据由当前 Windows 用户的 DPAPI 加密，更换电脑或 Windows 用户后重新填写。

备份时先关闭助手，再复制主目录及相邻的 `-run-tabs` 目录，保留数据库和可能存在的 `-wal` / `-shm` 文件。desktop.6 的独立 profile 保留在原处，升级后重新确认共享账号与绑定。

## 日志与常见问题

运行页右侧显示当前设备日志与画面。「记录 → 日志与诊断」可打开本机面板、导出诊断 ZIP、查看日志目录和崩溃记录；记录可按设备和账号筛选。诊断地址只监听本机，使用界面显示的地址即可。

| 现象 | 处理 |
| --- | --- |
| 找不到设备 / unauthorized / offline | 启动模拟器、打开 ADB 调试，核对端口并完成设备授权，再重新检测 |
| ADB 版本冲突 | 断开后选择对应模拟器的 ADB，检查其他工具是否占用服务 |
| 截图慢或黑屏 | 保持模拟器可渲染，查看截图测速；调整渲染设置后重新连接 |
| 触控未就绪 | 重新连接，或切换兼容模式后在非游戏页面测试 |
| 识别结果与画面不符 | 先用只读识别核对，保留原截图和相关日志，按需导出诊断包 |
| OCR 或原生库加载失败 | 重新解压完整程序；必要时安装微软官方 Visual C++ 2015–2022 x64 Redistributable |
| 界面空白 | 退出程序，设置 `SKIKO_RENDER_API=SOFTWARE` 后重试 |
| 网络连接失败 | 在设置中选择系统固定代理或直连；PAC 自动脚本暂不支持 |
| 复制数据后密码无法读取 | 在当前电脑和 Windows 用户下重新填写凭据 |
| 数据库下载后待生效 | 关闭并重启助手，等待暂存数据库安装 |

运行环境自检：

```powershell
.\LimingjieAssistant.exe --self-test --report report.json --data-dir '.\自检 数据'
```

自检检查资源、OCR 样图、数据库、加密及运行依赖，网络部分只做 TLS 握手。技术评估与历史记录见源码仓库的 `desktop/ocr/evaluation/` 和 `docs/desktop/reports/`。

## 使用风险与许可

- 本项目与游戏官方无关，自动操作和非官方接口访问可能导致账号限制或封禁。
- 购买、刷新、战斗和撤退会改变游戏状态或消耗资源；运行前核对账号与策略，异常时及时暂停或停止。
- 分享诊断包前检查截图与日志，移除账号、凭据及验证码等个人信息。
