# 执行包 v2 修订说明

修订日期：2026-10-25。对象：limingjie-desktop-execution-pack.zip。此次仅更新开发计划，不表示软件已开发或通过验证。

## 已确认的核心原则

> 业务能力和行为保持一致，界面按桌面使用方式重新设计。以 MAA 的操作组织方式为参考，形成完整、清晰、统一的黎明界桌面助手。

用户希望类似 MAA 的形态，允许调整、美化功能页面，并已授权按此原则更新。

## 最终产品预期

- Windows 独立桌面助手，解压双击 EXE 启动；原版账号库、黎明界、策略、编组、评分等功能在桌面窗口使用。
- 模拟器运行游戏，无需安卓版助手。桌面程序连接模拟器进行截图、识别和触控；本次未改为完全脱离模拟器的方案。
- 页面可重排和美化，统一导航、表单、字体、配色、间距、状态反馈和任务控制。功能行为兼容不要求外观一致。
- 保留共享源码、Compose Desktop、ADB / MaaTouch、OCR、账号协议、存储与便携打包路线；P2 不因美化自动进入本期。

## 修订内容

1. 移除强制整屏复用、禁止改布局和展示文案等呈现限制；重设计在桌面自有代码中实现。
2. 保留字段、默认值、范围、校验、保存 / 取消、确认、互斥和动作语义，业务与机器判断值不随美化改变。
3. 先展示主要页面原型和简短功能清单，再实现页面。按用户补充要求，不新增独立 Gate、不逐字段列证据、不要求全页面和全状态截图；授权内细节不逐页审批。
4. UI_PARITY 增加按功能分组的桌面去向简表。G4 收敛为功能是否遗漏、典型操作是否可用、代表页面是否正常；已有检查直接复用，不建立第二套验收。
5. 同步启动提示、分工、进度、决策编号、编译复用边界、上游同步与相关界面边界情况，避免矛盾指令。
