# P1 运行主界面调整

日期：2026-10-25。基于 `1b94742`，在独立分支 `codex/ux-vscode` 完成；未修改主目录。

## 行为

- 原三列改为主任务区与辅助区两栏。当前任务、常用参数、公会目标占据主区域；就绪详情可折叠，空闲日志限高，无历史时不显示历史卡片。沿用 VS Code 浅深色。
- 首页直接编辑五个公会的次数、通关/开局计数、难度、每区少拿格数（旧版路线则为完美开局）、刷到出或最大尝试次数。公会留空或 0 跳过，次数 1–99；难度使用当前账号已解锁选项，最大尝试次数沿用上游 1–800 校验。
- 保存/取消固定在底栏，未保存时底部开始与 F5 均被拦截；离开、切换任务或账号时可放弃草稿或留下继续编辑。高级配置仍打开完整原表单。
- 刷取规则通过原账号 Controller 保存；批量目标继续保存到已有 `settings/ui.json`，仅新增最近任务选择。重启恢复任务、目标和账号规则。单独刷开局的公会仍是本次临时选择，开始前的彻底撤退确认保留。
- 快捷保存仅覆盖用户实际改过的常用字段，保留实时账号配置中的 Boss、路线偏好及撤退规则；账号配置延迟加载不丢失已输入的目标。原完整配置保存并返回后，首页同步显示。
- 账号凭据缺失或尚在检查时，就绪提示与开始门控一致；原任务互斥及业务校验保留。
