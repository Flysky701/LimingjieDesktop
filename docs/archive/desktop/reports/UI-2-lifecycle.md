# 运行任务时的窗口生命周期补充检查

日期：2026-10-25。对象为已解压便携版 `1.0.18+desktop.1`，使用全新 `.tools/ui-task-lifecycle` 数据目录。目的仅为补查运行任务时的托盘及关闭窗口三分支，不重复 UI-1 和便携包首次启动检查。

## 实际经过与结论

- 初始只读查询确认 MuMu Android 12 实例 0 关闭。按授权启动该实例，确认系统启动完成；ADB 查询尺寸为 720×1280、密度 240、无 override，未修改显示设置。仅用 `am start` 打开 B 服，没有游戏点击、登录、凭据输入或协议业务调用。
- 助手使用指定实例 0 地址连接；连接尚在进行时切换了页面。源码中页面操作使用局部 scope，切页可能取消连接，但没有证据确定它是本轮连接失败根因。随后 Computer Use 报告外部用户输入、窗口已最小化；按工具指引刷新/激活产生恢复循环。只重置一次工具会话后恢复了窗口，没有使用其他方式绕过窗口自动化限制。
- 恢复后留在设备页重试连接，返回 10061（目标拒绝连接）。再次只读查询发现实例 0 已关闭；本轮此前没有发出关闭该实例的命令。存在其他操作或外部状态变化，原因未确认，因此未重新启动或继续争用。
- 通过助手 Alt+F4 正常退出，随后窗口枚举及进程查询确认本轮两个 launcher/JVM 进程均结束。最后实例 0 为关闭；没有操作外部实例 3，没有停止共享 ADB。临时数据保留在本机忽略目录。

**结果：未进入任务运行态，托盘暂停/继续/停止及关闭确认的取消、最小化、停止退出三分支仍未验证。** 本轮的空闲退出不替代这些验收项，不提交新的界面截图作为通过证据。

## 防睡眠查询限制

本会话执行 `powercfg /requests` 返回退出码 1：`此命令需要管理员权限，并且必须从提升的命令提示符中执行。` 未提权或操作 UAC。因此 L1-15 的命令输出证据仍缺失；主分支的真实 Windows API 状态/清理断言应单独记录，不能称为此命令验证通过。
