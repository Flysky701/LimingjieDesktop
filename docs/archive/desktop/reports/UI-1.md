本轮发现并收束两项问题：Main仅设AWT minimumSize时仍可缩窄，补Compose尺寸约束后复测通过；第一轮UI运行期间另一次测试重建shared JAR，导致延迟加载的开局按钮lambda出现ClassNotFoundException。类实际存在于新JAR，保持classpath固定并重启后同一路径及编组子页均通过，因此记录为并行构建干扰，不修改上游策略业务。对应截图07保留复现，08/09为复测成功证据。

源码审阅补齐账号互斥：正在运行、启动或停止任务时，新建、编辑字段/服务器、保存、删除确认均禁用；取消可用。该状态分支本次未用真实游戏任务驱动，不能将源码检查写为实机运行验证。
