# 用户实机验收清单

本清单保留完整的真实设备验收步骤；本轮已执行范围和证据以 `FINAL_REPORT.md` 及 `reports/L1-MuMu.md` 为准，不需要重复已经通过的同环境检查。当前 OCR 为 14/15，距 80 个真实样本还缺 65 个，且角色奖励类别尚无样本；仍需补齐 L2-04 后重跑准确率门槛。L2-06 的真实公开下载、SQLite 占用暂存与新进程恢复安装已通过，见 `reports/L2-CnDatabase.md`。请先阅读 README-desktop 的风险说明，使用独立数据目录；不要导入或覆盖旧项目数据。

出现问题时，附上助手版本、模拟器名称/版本/Android 版本、复现步骤、相关截图及“日志与诊断 → 导出诊断包”。不要发送密码、access_key、验证码链接或未检查的敏感截图。

## desktop.6 多开增量验收

待当前测试结束后再打开新版。两个标签分别连接两台模拟器并选择不同账号，确认每台模拟器里登录的游戏账号与标签一致；每个账号先「读取当前开局」完成身份确认。

| 操作 | 预期结果 |
|---|---|
| 在标签 1 修改未保存的策略，切换到标签 2，再返回 | 页面位置和编辑草稿保留，标签 2 的配置不变。 |
| 两个标签分别开始任务，再切换、暂停或停止其中一个 | 操作只影响目标标签，另一个继续运行；日志、画面和记录对应正确实例。 |
| 标签 2 尝试连接标签 1 已占用的模拟器或别名地址 | 提示已被占用，不安装或替换该模拟器的触控服务。 |
| 两个标签选择同一个真实账号并尝试运行 | 后启动的账号任务被拦截。 |
| 关闭其中一个运行中的标签 | 确认后停止并关闭此实例，其他标签继续；重新打开仍保留该实例数据。 |
| 后台标签遇到验证码 | 标记对应标签，验证码只在切回该标签后显示。 |
| 点击「停止全部」，或退出窗口选择「停止全部并退出」 | 所有实例停止；退出后没有本次总控遗留的后台控制进程。 |

本轮离线验证不能替代上述双模拟器并行业务验收。

## 发行与自检

将便携包解压到含中文和空格的可写目录，在该目录打开 PowerShell：

```powershell
Get-FileHash '.\LimingjieAssistant-desktop-1.0.18+desktop.1-win-x64.zip' -Algorithm SHA256
.\LimingjieAssistant.exe --self-test --report '.\自检结果.json' --data-dir '.\自检 数据'
```

第一个命令应在 zip 所在目录执行，并与随包 `.sha256` 对照。第二个命令应在 exe 所在目录执行。检查 JSON 的 `passed` 与逐项状态；网络不通时 TLS 可以明确记为 skipped，其余错误需要反馈。自检只使用临时假数据，不会登录游戏。

云端 CI 还需要可写的项目远端与 GitHub Actions 运行记录；本地命令结果不等同于云端三个 job 已通过。
