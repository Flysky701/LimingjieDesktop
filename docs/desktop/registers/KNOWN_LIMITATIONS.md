# KNOWN_LIMITATIONS.md —— 已知限制

**规则**：每条写明影响、规避方法、是否计划处理。执行中新发现的限制追加到对应 WS 小节（子代理只改自己的小节）。最终报告和 `README-desktop.md` 的「常见问题」都从这里摘取。

## 方案阶段已知

| # | 限制 | 影响 | 规避方法 | 计划 |
|---|---|---|---|---|
| KL-01 | 只发行 Windows 10/11 x64 | Windows on ARM 未测试（x64 模拟层可能可用） | — | P2 |
| KL-02 | 发行包未做代码签名 | 首次运行出现 SmartScreen 提示，部分杀软可能误报 | README 说明「更多信息 → 仍要运行」；提供 SHA-256 校验方法 | 有证书后处理 |
| KL-03 | 官方支持 MuMu 12（B 服）和雷电 9（渠道服），1920×1080 横屏 | 其他模拟器、手机实机未验证 | 「自定义 ADB 地址」实验性使用 | — |
| KL-04 | adb 不随包分发 | 没有装模拟器自带 adb 的环境需要用户自行提供 | 设备页提供「指定路径」和下载说明 | — |
| KL-05 | 单设备、单任务（D-17） | 不能同时控制多个模拟器 | 复制多份程序或使用不同 `--data-dir`（未正式验证） | P2 |
| KL-06 | 代理：只支持系统固定代理和直连；`useSystemProxies` 不执行 PAC 脚本 | 使用 PAC / WPAD 自动配置的网络里，GitHub 数据库下载可能失败 | 在系统中配置固定代理，或切换为直连 | P2 视反馈 |
| KL-07 | 内置 JRE 使用自带的根证书库，不读取 Windows 证书存储 | 企业网络中做 TLS 中间人检查时，连接可能失败 | 换用家庭网络 | P2 视反馈（可评估 `Windows-ROOT` 信任库） |
| KL-08 | 凭据用 DPAPI 绑定到当前 Windows 用户 | 数据目录复制到其他电脑或其他用户后，已保存的密码无法解密（FB-12） | 重新填写密码 | 设计如此 |
| KL-09 | 截图依赖模拟器持续渲染 | 模拟器窗口最小化或渲染模式不兼容时可能出现黑帧（10 s 后警告） | 不要最小化模拟器；调整渲染模式 | L1-13 记录实际表现 |
| KL-10 | 防睡眠只阻止系统空闲睡眠 | 合上笔记本盖子、手动睡眠或锁屏策略仍会中断任务 | 调整电源设置 | — |
| KL-11 | 人工验证码在系统浏览器中完成 | 没有默认浏览器或浏览器无法访问回环地址时需手动复制链接（FB-05） | 复制链接到浏览器 | R-02 备选 KCEF |
| KL-12 | 会战助手不提供界面 | 与上游 1.0.18 一致（上游导航未接入） | — | 上游接入后跟进（EDGE J-08） |
| KL-13 | 首次启动需要加载 OCR 模型 | 首次识别前有数秒延迟 | 加载期间请求排队，不影响结果 | — |
| KL-14 | 必须关闭游戏内「播放角色加入动画」 | 与上游要求一致 | README 中说明 | — |
