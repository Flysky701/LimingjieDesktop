# 黎明界助手 Windows 桌面版 1.0.18+desktop.11

Windows 10/11 x64 便携版，内置 Java 21。用户已完成当前版本的基本实机测试，本版包含 desktop.8–11 累积修复。

## 主要变化

- 修复第五区末尾 Boss 缺少结束标记时，继续寻找下一节点导致异常停止的问题。
- 稳定识别最终结果页即可确认通关，最多等待 6 秒采集分数，然后结束单局并报告耗时与分数；不再要求关闭结果页、领取奖励或返回主页。
- 运行记录保存单局分数，近 14 天统计有效分数样本数、平均分和最高分。未识别的分数不当作 0 分，旧历史格式保持兼容。
- 修复 ADB 冷启动后连接重置，保留共享 ADB 服务；改善设备自动发现和空闲记录清理。
- 按页面及窗口可见性生成预览，复用未变更的日志、历史和角色数据，减少重复传输与图片处理。
- 恢复托盘中文菜单、主题及定位相关修复。

## 下载与更新

下载下方 Windows ZIP 和同名 `.sha256` 文件，完整解压后运行 `LimingjieAssistant.exe`。包内含使用指南、许可文件及修复说明。

更新已有目录前，正常退出助手并备份。完整替换 `app`、`runtime`、`licenses` 及程序文件，保留现有 `data`、`data-run-tabs` 和自有文件；自定义数据目录也需单独保留。不要用删除整个旧目录的方式更新。

- 当局结束、历史统计和分数识别的 53 项定向检查通过。
- 安装后的 10 项运行环境自检通过；公开包的 458 个程序、运行环境和许可文件与该已验证版本一致，仅更新发行文档。
