# desktop.8 基础版说明

版本：**1.0.18+desktop.8**。整理日期：2026-10-27。状态：**测试候选，待用户实机测试后发布**。

本版本冻结当前兼容路线的成果，以 desktop.7 为基础。独立分支为 `codex/baseline-desktop-8`。内部拆解路线继续保存在 `codex/logic-decomposition`，没有整体合入本候选版。

## 本次包含

| 范围 | 已完成内容 |
|---|---|
| 桌面预览 | 同一预览不重复解码；预览最长边缩至 960 像素，小图不放大，识别原图不变。 |
| 状态转换 | 未变化的日志、历史列表和接收端角色目录复用转换结果；发送端复用角色目录 JSON 节点。 |
| 设备发现 | 进入设备页自动检测，展示进度与失败原因；沿用 MuMu 实际端口发现和 ADB 自动登记。 |
| 设备记录 | 成功检测后清理未发现的空闲记录；失败时保留记录，运行中、连接中或有草稿的会话暂不清理。账号、任务配置和历史保留。 |
| 坐标兼容 | 备用点击点与标准锚点统一使用居中等比坐标映射；1920×1080 的参考点不变。 |

沿用 desktop.7 的共享账号与策略、每设备运行标签、后台进程隔离、草稿保留和任务控制。自动视觉执行仍要求实际截图为 1920×1080，不将局部坐标验证描述为所有分辨率已兼容。

## 本次未纳入

诊断图片异步处理、不可见预览停止生产、截图复制优化、页面识别快速路径、增量状态协议与共享 OCR 均留待后续。拆解版的业务状态迁移及行为修正未合入。

五项公共优化已有定向检查，设备改动已有定向检查和先前本机验证；坐标修正已有 11 项离线检查通过。本次复用这些结果，最终候选包的构建与运行检查另记于源码仓库 `docs/desktop/reports/BASELINE-DESKTOP8-VALIDATION.md`。

尚未测量整机 CPU、内存与任务耗时收益，未完成本候选包的真实账号登录和完整游戏循环验收。OCR 现有归档结果为 14/15，准确率目标与样本覆盖尚未达到；没有为此修改识别门槛或 CI 检查。

## 测试与反馈

将 ZIP 解压到一个新的可写目录，双击 `LimingjieAssistant.exe`。程序包含 Java 21，便携标记使数据保存在此候选版目录；不要覆盖旧版目录。需要沿用数据时，先关闭相关程序，再复制主数据目录及其相邻的 `-run-tabs` 目录，保留原件。

优先完成随包 `用户验收清单.md` 顶部的五项单开检查。问题反馈注明版本、复现步骤、所在页面和必要的脱敏日志。已发布版本仍保留，本地候选包不会自动更新或替换它。

测试通过后再决定发布。当前仅整理源码和本地候选包，未上传 Release，未推送正式发布标签。远端发行流水线的完整检查状态须在发布时单独确认，本地候选包构建不等于远端门禁通过。
