# VS Code 配色 UI：本轮保留状态

日期：2026-10-25。用户确认“先改成这样就行了”，本轮按当前效果收尾，不继续追加改版、实机采集、便携 ZIP 或交接包。

## 已保留的实现

- 配色改为 VS Code 默认 **Light Modern / Dark Modern**，并支持跟随系统。完整 Material 颜色、字号、圆角与语义色集中在 `DesktopTheme.kt`；桌面自有页面和上游表单共用主题。主题值参考 [Light Modern](https://github.com/microsoft/vscode/blob/main/extensions/theme-defaults/themes/light_modern.json) 与 [Dark Modern](https://github.com/microsoft/vscode/blob/main/extensions/theme-defaults/themes/dark_modern.json)。
- 六项导航：运行、账号、策略、设备、记录、设置。运行台有真实就绪状态、五个任务入口、配置摘要、阶段/路线/角色/遗物/决策面板、预览和分类日志；固定底栏保留开始、暂停/继续、停止与窗口内快捷键。
- 完整任务配置继续复用 `LabyrinthScreen`；重复批量任务可使用上次启动时保存的目标。原有策略和编组表单保留，策略表单通过约 880dp 桌面模态外框承载。
- 角色评分提供桌面表格、属性/定位/已修改筛选、排序、键盘移动、0–100 输入和恢复原评分；保留原版入口。应用到草稿、保存、取消与离开确认分开处理；原评分预填采用与上游相同的四舍五入。
- 新增桌面运行记录 `runs.jsonl`，记录结果、耗时和停止原文；损坏行跳过并提示，未完成记录在下次启动补记。保留最近 5000 条或 180 天；统计图仅使用已有明确通关记录。
- 日志显式分类、连续重复计数、过滤、搜索与复制；上游转发默认普通，不按文案猜等级。保留 2000 条上限。
- 设置分组、主题/字号/通知偏好、三步向导、设备高级选项和一键连接、账号状态徽标、托盘状态及验证码提示均已加入。

界面偏好单独存储在 `settings/ui.json`。没有读取或迁移旧 Python 项目的账号数据；没有把真实凭据写进源码或截图。

- Windows 编译、`createReleaseDistributable` 成功，显示版本 `1.0.18+desktop.2`。当前只生成了本地应用镜像，没有新的便携 ZIP。
- 定向检查通过：运行记录 3 项、presenter/日志/评分/导航草稿 5 项、Compose 开始门控及停止详情 1 项、真实 Graph + 假设备 I/O 的识别/暂停/停止/资源释放 1 项；版本断言 2 项通过。相关检查分批执行，没有重复运行全仓回归。
- HTML 设计稿已同步为新配色，20 组布局与代表性交互检查通过；其示例数据不作为真实游戏验证。
- 实际窗口观察确认浅深色切换、固定底栏和原版策略表单模态外框可显示。`evidence/ux/native/` 的三张早期截图保留来源说明，不作为最终完整截图矩阵。
- `android/`、`desktop/ocr/`、`desktop/device/` 无本轮改动。Graph 仅增加只读体验观察器、缓存刷新、日志分类及退出释放；任务、识别、策略、触控和截图时序保持原实现。

## 尚未验收的事项

- 10 分钟 MuMu 性能、运行态托盘/关闭三分支、完整原生 DPI 截图矩阵没有完成。历史地址 `127.0.0.1:16384` 在本轮检查时拒绝连接；按用户收尾指示，不继续查找或采集。
- 策略外框的原生 Alt+F4 / X 转发 Escape 尚需复核：一次 Alt+F4 操作未使外框关闭；上游表单内的返回、保存和草稿确认入口仍保留。没有据此宣称关闭交互已全部验收。
- 字体做过应用密度渲染比较，未改系统 DPI 或字体光栅化参数；未将实验渲染称为 Windows 实机缩放验证。未完成的矩阵实验和输出留在本机忽略目录 `.tools/ux-render-experiment/`。
- 既有 OCR、标题误判、真实登录与完整游戏循环的限制保持原结论，未在 UI 轮修复。
