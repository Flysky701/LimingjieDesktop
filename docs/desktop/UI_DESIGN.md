# 第一版桌面原型

采用浅色主题、紫色强调色，左侧主导航；任务页中部配置、右侧日志，底部持续显示任务状态及控制。账号库采用列表与编辑区分栏；策略设置采用分类导航与表单。

## 已展示

- 黎明界：当前账号、画面自动化 / 刷开局 / 只读识别、策略入口、日志、画面预览和任务控制。
- 账号库：示例账号选择、别名编辑、新增与删除确认。
- 策略：评分、选人、Boss、遗物、商店、事件与响应速度。保存、取消和恢复默认在原型中演示。
- 设备、设置与环境、诊断：主要布局和入口预览。
- 开局编组、角色评分和遗物优先级详情：仅保留入口，未完成详情页面。
