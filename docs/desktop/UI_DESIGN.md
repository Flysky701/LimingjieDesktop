# 桌面界面设计记录

2026-10-25：沿用已保存原型的浅色紫色方案（#6952d5）、白色面板、淡灰背景、固定左导航。正式实现位于 desktop/app/.../ui/，与HTML示例分开保存。

默认总览提供账号/设备/任务状态；任务页突出当前账号、读取开局、完整执行配置与只读工具；账号列表和编辑区分栏。宽窗口的任务页右侧显示日志与可折叠预览，窄窗口收起侧栏，底部状态/停止始终保留。使用Microsoft YaHei UI（不可用回落系统字体），无额外字体资产。

完整批量目标与刷取配置以宽对话框复用LabyrinthScreen；策略、开局编组、角色评分复用上游完整表单，保留字段/范围/确认/保存/取消。桌面新布局不改业务算法。设备、环境、日志与首次向导为桌面自有页面。

用户已查看第一版原型；本轮按开发授权完成真实窗口检查，未把代理检查写为用户最终确认。默认1280×800及最小1100×700均可使用，窄窗口自动收起任务日志侧栏，长表单可滚动，底部控制保持可见。首次发现系统窗口尺寸约束未生效，Main补Compose尺寸约束后复测通过；初始位置改为主屏可用区域居中。见 [UI-1](reports/UI-1.md) 与 evidence/ui/。
