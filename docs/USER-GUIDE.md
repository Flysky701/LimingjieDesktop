# Windows 桌面版使用指南

助手在 Windows 中提供运行、账号、设备、策略、记录和设置六个页面。模拟器只需运行游戏。

## 安装与启动

系统要求：Windows 10 1809 或以上 / Windows 11 x64，至少 4 GB 内存，另为模拟器预留运行内存。程序自带 Java 21。

1. 下载 Windows ZIP 和同名 `.sha256` 文件，核对校验值：

   ```powershell
   Get-FileHash .\LimingjieAssistant-*.zip -Algorithm SHA256
   ```

2. 将整个 `LimingjieAssistant` 文件夹解压到可写目录，例如 `D:\Tools\LimingjieAssistant`。
3. 双击 `LimingjieAssistant.exe`，按首次向导完成准备。未签名程序可能出现 SmartScreen 提示；确认下载来源和校验值后，按 Windows 提示继续。

## 连接模拟器

1. 推荐使用 MuMu 12 或雷电 9，设置为 **1920 × 1080 横屏**，开启 ADB 调试。
2. 进入「设备」页会自动检测，选择在线设备并连接。MuMu 会读取实际运行端口并自动登记，无需手填地址；同一设备的多个地址合并显示。模拟器后启动时可点击「重新检测」，其他设备仍可填写 `127.0.0.1:端口` 后点击「添加并连接」。
3. 找不到 ADB 时，展开「高级：ADB 工具与路径」，选择模拟器自带的 `adb.exe`，或下载官方 Platform Tools。更换路径前先断开设备。
4. 等待安装信息核验、截图测速和触控准备完成，进入「设备详情」查看结果。

检测成功后会移除本次未发现的设备记录；暂时关闭的模拟器也会从列表消失，再次启动后可重新检测添加。检测失败时保留原记录。运行中、连接中或有未保存修改的会话暂不清理；账号、已保存任务配置和历史记录不受影响。

运行中若 ADB 短暂离线或身份查询超时，首次检查失败后最多等待 30 秒重新确认同一设备的启动身份；提前确认便立即继续当前任务。模拟器已经重启或持续失联时，助手会停止任务并记录原因。

MaaTouch 是默认触控方式；有兼容问题时可切换为 ADB 输入并重新连接。「测试点击」用于在非游戏页面中央点击一次。

自动执行在任务启动时按实际截图检查，支持 1920 × 1080 和 1280 × 720 横屏；720p 已开放测试。其他尺寸可用于连接、预览和只读识别。游戏内请关闭「播放角色加入动画」，运行时保持游戏在前台。

## 账号与任务

1. 在「账号」页新增账号并选择服务器。B 服填写登录账号与密码；渠道服填写 `uid` 和 `access_key`。更换服务器时重新填写凭据。
2. 在「设备」页绑定账号，再打开运行页。**绑定只选择助手使用的凭据，模拟器内的游戏账号需要自行核对。**
3. 使用「登录并读取」查看当前开局。遇到验证码时，在系统浏览器中完成；打不开浏览器时可复制验证链接。
4. 在运行页设置十个公会的目标、计数方式、难度和常用参数，留空的公会会跳过。路线、Boss 和撤退选项位于「高级配置」；路线模式支持「高价值路线」、「官方高分路线」和「节点模板路线」，其中自定义路线可指定节点类型，并预览路线判定。彻底撤退会放弃当前开局，启用前确认保留需求。
5. 在「策略」页新建或编辑方案，按左侧分类配置开局阵容、Boss 编组、事件选项和个人评分，再保存并启用。所有设备下一次任务使用当前启用的策略；运行中的整批任务保留启动时的策略。「事件自定义」需开启总开关才生效，指定分支不可用时沿用自动选择。

「策略」页的「迷宫战斗价值估计」面板默认内置来自 [黎明界NN（LimingjieNN）](https://github.com/Flysky701/LimingjieNN) 的本地 ONNX 战斗模型与全局规划能力，提供「使用本地 ONNX 战斗选队模型」（EX / Boss 生效）和「启用 Path B 全局收益规划」（角色 / 遗物 / 商店 / 事件生效）开关，并支持设置自定义模型目录与「校验并重载」；关闭或校验失败时自动回退到规则评分。

策略卡片的「更多」中可以修改名称与备注、创建副本、分享配置和删除。首次使用会将原配置保留为「我的策略」。编辑中返回或切换页面时，助手会提醒处理未保存的修改。

「分享配置」可选择策略、个人评分和某个账号的刷开局设置，分享码可与 Android 端互通。接收方复制完整分享码，点击「导入配置」，先查看变化，再选择目标策略及刷开局账号；确认后一次保存所选模块，并可撤销最近一次导入。后续手动保存配置会取消该撤销入口。清空个人评分需要单独勾选确认。旧桌面分享码仍会导入为新策略，同名自动加后缀，不会自动启用。分享内容不包含凭据、设备和运行记录。

删除已启用策略前需先启用其他方案；最近一次删除前的完整策略库保存在数据目录的 `settings/strategies.before-delete.json`。需要恢复时先退出助手，备份现有 `settings/strategies.json` 后用该备份替换；该文件也包含各账号的刷开局配置，恢复时会一并回退。

「只读识别」分析当前画面；「执行入口流程」与批量任务会操作游戏。批量启动时，助手会按所绑定账号的服务器关闭并重启对应游戏进程。

## 多设备与运行控制

每台设备有独立运行标签和后台进程，切换标签保留任务与编辑草稿。账号、账号配置、全局策略和汇总记录由所有设备共用；任务目标与任务选择分别保存在各设备运行页。

| 操作 | 作用 |
| --- | --- |
| F5 | 开始当前运行页任务，需先保存配置 |
| F6 | 暂停 / 继续当前画面任务 |
| F7 | 停止当前运行页任务 |
| 停止全部 | 停止所有设备任务 |
| 关闭运行标签 | 停止该设备任务并关闭会话；运行中或有草稿时提示确认 |
| 关闭主窗口 | 有任务或草稿时选择最小化、停止全部退出或取消 |

账号、策略等全局页面不处理运行快捷键。网络刷开局支持停止；画面任务另支持暂停与继续。后台标签遇到验证码时会显示提醒，切回该页处理。

同一模拟器按启动身份识别，同一账号限制并发运行。重开助手后手动连接设备；模拟器启动身份未变时可恢复配置与绑定，重启模拟器后重新确认账号。运行期间账号绑定和设备连接保持锁定。

## 数据与备份

| 位置 | 内容 |
| --- | --- |
| 程序旁的 `data` | 带 `portable.flag` 时使用的主数据目录 |
| `%LOCALAPPDATA%\LimingjieAssistant` | 移除便携标记后的默认主目录 |
| `<主数据目录名>-run-tabs` | 与主目录相邻，保存窗口状态、设备会话及各设备的任务配置与缓存 |

可用 `--data-dir <目录>` 指定主目录。同一数据目录只允许一个助手实例。凭据由当前 Windows 用户的 DPAPI 加密，更换电脑或 Windows 用户后重新填写。

备份时先关闭助手，再复制主目录及相邻的 `-run-tabs` 目录，保留数据库和可能存在的 `-wal` / `-shm` 文件。更新时先退出助手并备份，仅替换程序文件，保留数据及自有文件。

## 日志与常见问题

「记录 → 运行记录」按通关顺序展示单局分数和耗时。折线看左轴分数，柱形看右轴耗时。图表、平均耗时和分数摘要只使用已通关且已识别到有效分数的单局，默认展示最近 50 局，也可选择最近 100 局、200 局或全部。鼠标移到图上可查看该局的完成时间、分数、耗时、账号、设备和策略。

记录可按账号、策略及修订筛选。历史记录没有策略信息时显示「未记录策略」。修改或删除策略不会改写历史名称。最多保留最近 5000 条记录及 180 天，条数包含任务汇总，不等同于局数。

运行页右侧显示当前设备日志与画面，可点击「导出ZIP」。也可在「记录 → 日志与诊断」查看事故快照数量、打开日志目录和查看崩溃记录，或点击「导出诊断包」直接保存 ZIP。诊断包包含近期识别状态、脱敏日志和最近的事故现场 PNG。此外，「设置 → 数据库与本地数据」和「记录 → 日志与诊断」均支持导出匿名回放数据（`replays.jsonl`，不含账号信息）供离线评测使用。

| 现象 | 处理 |
| --- | --- |
| 找不到设备 / unauthorized / offline | 启动模拟器、打开 ADB 调试，核对端口并完成设备授权，再重新检测 |
| ADB 版本冲突 | 断开后选择对应模拟器的 ADB，检查其他工具是否占用服务 |
| 截图慢或黑屏 | 保持模拟器可渲染，查看截图测速；调整渲染设置后重新连接 |
| 触控未就绪 | 重新连接，或切换兼容模式后在非游戏页面测试 |
| 识别结果与画面不符 | 先用只读识别核对，保留原截图和相关日志，按需导出诊断包 |
| OCR 或原生库加载失败 | 重新解压完整程序；必要时安装微软官方 Visual C++ 2015–2022 x64 Redistributable |
| 界面空白 | 退出程序，设置 `SKIKO_RENDER_API=SOFTWARE` 后重试 |
| 网络连接失败 | 在设置中选择系统固定代理或直连；PAC 自动脚本暂不支持 |
| 复制数据后密码无法读取 | 在当前电脑和 Windows 用户下重新填写凭据 |
| 数据库下载后待生效 | 关闭并重启助手，等待暂存数据库安装 |

运行环境自检：

```powershell
.\LimingjieAssistant.exe --self-test --report report.json --data-dir '.\自检 数据'
```

自检检查资源、OCR 样图、数据库、加密及运行依赖，网络部分只做 TLS 握手。

## 使用风险与许可

- 本项目与游戏官方无关，自动操作和非官方接口访问可能导致账号限制或封禁。
- 购买、刷新、战斗和撤退会改变游戏状态或消耗资源；运行前核对账号与策略，异常时及时暂停或停止。
- 分享诊断包前检查截图与日志，移除账号、凭据及验证码等个人信息。
