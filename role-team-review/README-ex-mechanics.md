# 黎明界 EX / Boss 机制参考

本页汇总上游审阅阶段的特殊战斗机制和应对建议。操作入口见[用户指南](../README-desktop.md)，配队模型见[模型说明](README-combat-model.md)。

## 原审阅方案：一队先打，失败后特化

原方案建议如下，保留用于策略讨论：

1. 使用当前候选池评分最高的完整第一队直接进入战斗。
2. 第二、第三队不得为了理论三队总分反向削弱第一队。
3. 只有首战实际失败，或游戏已经明确展示特殊机制时，才进入机制应对。
4. 机制应对优先点击战斗编组属性栏最后一项 **“有效效果”**，利用游戏自身筛选出的有效角色池，再从其中按玩家评分 / 当前系统适配重新编队。
5. 如果“有效效果”仍不足以唯一确定打法，再结合下方机制标签选择 Dot、控制、嘲讽、群攻、护盾、多前排或治疗等特化方向。

当前正式流程在 EX/Boss 编组前扫描「有效效果」，Boss 默认多队，也可在策略中改为单队。以下机制表用于辅助选择应对方向。

## Boss 机制

| 敌人 | 机制重点 | 失败后优先应对 |
| --- | --- | --- |
| 幽灵领主 | 魔攻。UB 锁定最前角色并以其为中心半径300结算圆内总最大生命值；圆内人越多伤害越高并削减生命上限。 | 1坦 + 4中后排，尽量拉开主坦与队友；可考虑抽 TP 或降低敌方魔攻。 |
| 好朋友X | 极高生命和防御，但所有 Dot 伤害固定为50万。 | 高优先级切 Dot 队。 |
| 岛鲸 | 1阶段周期生成高防屏障5秒；30%血以下进入2阶段，对前4名持续造成高额魔法伤害。 | 伤害 UB 尽量避开屏障；2阶段补群体生存，尤其魔法防护。 |
| 反物质兽 | UB 随机：40%全队物攻-90%、39.6%全队魔攻-90%、20.4%全队眩晕5秒；群攻频率较高。 | 允许 SL；补一定治疗/续航，不为随机结果过度改首战队。 |
| 巨型吞拿鱼 | UB 对前三位造成其当前生命70%的物伤，同时 Boss 自损等同本次UB总伤害×10000。 | 上治疗稳血；若输出不足，不要带扣/偷敌方 TP 的角色。 |
| 熔岩龙 | UB 对最前角色造成超高物伤；其半径400内其他我方角色可协助分摊。 | 多名前排集中站位帮助主坦分摊。 |
| 蜂后 | 初始守护机兵；召唤3只蜜蜂。蜜蜂吸第2~4位TP、提高蜂后攻击并回TP，受控制时这些效果暂时失效；Boss死后召唤物退场。 | Dot 清守护机兵；控制蜜蜂；随后集中速杀蜂后。 |
| 美空 | 初始治愈机兵并召唤高耐久玩偶；玩偶很难击杀；Boss UB 随机单体7次并强化玩偶。 | 不打玩偶；用群攻越过玩偶清治愈机兵并攻击美空，必要时配位移。 |

## 遗迹机兵机制

| 机兵 | 机制重点 | 失败后优先应对 |
| --- | --- | --- |
| 群攻机兵 | 每次行动对全队造成各自最大生命35%的物伤，并使吸血-100%。 | 治疗/持续回复稳住血线。 |
| 守护机兵 | 每3秒若不处于控制状态，使己方全体受到的非Dot伤害-99%持续3秒；自身所有Dot固定50万。 | 首选 Dot；备选高频控制阻止技能。已知可用方向包括江户深月、美咲、瓜眼、狼布丁等。 |
| 狙击机兵 | 每次行动以高额固定攻击随机攻击1人3次，可重复命中；特定敌人还会攻击我方魔攻最高角色。 | 优先嘲讽；无嘲讽时才考虑 SL。 |
| 破坏机兵 | 每次行动全队防御-15%，持续30秒且可叠加。 | 速战速决，优先爆发。 |
| 治愈机兵 | 每次行动把同阵营其他单位生命回满。 | 群攻越过前排切掉治愈机兵；范围不足时考虑位移。 |
| 诅咒机兵 | 每次行动全队1000物伤+1000魔伤；未被护盾抵消时降低对应攻击属性。 | 优先护盾。 |

## 状态建模建议与现有实现

原方案的状态划分建议：

```text
FIRST_ATTEMPT
FIRST_ATTEMPT_FAILED
MECHANIC_FILTERING
SPECIALIZED_RETRY
MULTI_TEAM_FALLBACK
```

方案中，`FIRST_ATTEMPT` 使用最佳第一队，失败后做机制特化和多队兜底。现有编组、扫描和恢复逻辑位于 `LabyrinthEntryRecognitionSession`、`LabyrinthTeamOptimizer` 与 `LabyrinthStrategySettings`。
