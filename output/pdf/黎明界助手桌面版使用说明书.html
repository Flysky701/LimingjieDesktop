黎明界助手桌面版

适用版本：1.0.18+desktop.11 · Windows 10/11 64 位

1 项目来源与桌面版调整

本项目是 wbero「黎明界助手」Android 1.0.18 的 Windows 移植版。刷开局、画面识别、路线执行、自动编组和策略等核心能力沿用原项目，感谢原作者的开发与开源。

原作者 wberohttps://github.com/wbero

原项目https://github.com/wbero/limingjie-assistant

  • 使用方式：原项目在 Android 内运行，通过屏幕捕获和无障碍服务操作游戏；桌面版在 Windows 中配置任务，通过 ADB 连接模拟器，使用 MaaTouch 或 ADB 输入。
  • 桌面适配：提供多设备运行标签、共享账号与策略、快捷键、停止全部和托盘，在电脑上集中查看运行记录。
  • 本版更新：最终结果页稳定识别后计通关，记录分数与耗时，统计近 14 天均分和最高分；另包含桌面版的 ADB 冷启动、画面预览与托盘修复。

更新：退出助手，将新版解压后的文件覆盖到原程序目录，再启动助手。

3 简短使用手册

  1. 准备游戏：模拟器设为 1920 × 1080 横屏，开启 ADB 调试；游戏内关闭「播放角色加入动画」，运行时让游戏保持前台。
  2. 连接设备：进入「设备」页检测并连接。MuMu 自动读取端口；找不到 ADB 时，在高级设置中选择模拟器自带的 adb.exe。
  3. 绑定账号：在「账号」页选服务器，B 服填账号密码，渠道服填 uid / access_key，再到设备页绑定，并核对游戏内账号。
  4. 开始任务：在设备运行页选「批量自动执行」，填写公会、次数、计数方式和难度，保存后查看「运行检查」，按 F5 开始。策略页的修改从下一次任务启动时生效。

运行控制：F6 暂停 / 继续画面任务，F7 停止当前任务，「停止全部」停止所有设备。到「记录」页查看结果与日志。

需要验证码时，按提示在浏览器中完成。
