# 黎明界助手 1.0.17 产品测试更新说明

日期：2026-10-15　版本号：1.0.17（10017）　状态：测试版

## 本版更新

1. **修复事件、商店自选角色的候选名单。** 获取角色页面不再沿用上一场战斗的已加入角色名单，避免未获得角色被相似的已获得角色替代、随后被选角策略排除。头像识别的置信度和差值门槛保持原有要求。
2. **修复会话恢复后自选页一直等待的问题。** 选人及邀请确认改用已有冷却计算，正确处理恢复后清空的动作时间，同时保留手势落地后的等待间隔。
3. **调整设置页的截图授权入口。** 截图授权由视觉任务启动入口请求；设置页显示捕获运行状态，运行时仍可停止捕获。
4. **同步诊断面板说明。** Debug 与 Release 均在应用启动时开启本地诊断面板，仅监听设备本地回环地址 `127.0.0.1:8765`。

## 建议重点测试

| 场景 | 操作与预期 |
| --- | --- |
| 战斗后进入事件自选 | 核对尚未获得的角色可正常识别、选择，并继续邀请确认。 |
| 战斗后购买商店选择印记 | 核对全列表角色候选不受上一场编队名单限制，能够继续选择及确认。 |
| 会话恢复后进入自选页 | 稳定识别后应继续选人或邀请确认，不应永久停在冷却等待。 |
| 最近刚完成手势 | 保留正常冷却间隔，避免连续点击；冷却结束后能够继续。 |
| 启动视觉任务 | 未开启捕获时由任务入口请求系统授权；设置页可查看状态及停止捕获。 |
