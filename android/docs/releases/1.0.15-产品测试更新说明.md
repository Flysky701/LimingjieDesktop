# 黎明界助手 1.0.15 产品测试更新说明

日期：2026-10-02　版本号：1.0.15（10015）　状态：测试版

## 本版更新

1. **修正龙妈与惠理子的编组识别。** 更正帆稀（龙妈）的升星头像模板，避免成员栏无法可靠识别或误认角色。
2. **单独刷开局的公会选择生效。** 辅助工具按本次所选公会刷取，不再忽略界面选择。
3. **初始选人继续下滑查找。** 找不到目标角色时继续搜索；滚动条未测得、全高或卡片身份未识别不再直接判为到底或越界回弹。
4. **更新咲恋救济院默认初始方案。** 第三个角色由水电改为圣诞咲恋，默认三人为铃莓、铃莓（春日）、咲恋（圣诞节）。
5. **更新自动执行说明与权限引导。** 删除要求人工选角色、编组和遗物的半自动说明；启动自动执行时缺少无障碍权限或服务未连接会弹出确认框，可跳转系统无障碍设置。
6. **修复冷启动接管与延迟初始选人。** 目标游戏已在前台时直接接管识别；短暂出现地图后才弹出的初始选人页仍按公会初始方案处理。

## 建议重点测试

| 场景 | 操作与预期 |
| --- | --- |
| 成员栏识别 | 将龙妈与惠理子同时加入编组，两人的身份应分别识别。 |
| 单独刷开局 | 分别选择不同公会启动，核对实际开局公会与界面选择一致。 |
| 初始角色查找 | 目标不在首屏时应下滑查找；咲恋救济院未设置自定义方案时应选择圣诞咲恋。 |
| 无障碍权限 | 关闭助手无障碍服务后启动自动执行，应弹出确认框；确认打开系统设置，取消留在助手。开启服务后返回并再次启动任务。 |
| 冷启动与继续挑战 | 验证 B 服及渠道服的游戏接管，以及地图短暂出现后弹出初始选人的流程。 |
