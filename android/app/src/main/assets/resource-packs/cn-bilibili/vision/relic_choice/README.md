# 迷宫遗物三选一

2026-10-26 按当前共享识别与遗物策略接线核对。本目录是 Android 与桌面共用的页级素材，不是遗物身份库或选取策略定义。

本目录只用于识别“获得道具的机会”页面中“请选择要获得的迷宫遗物”这一页级指令。

它与 `vision/link_choice/` 分开：连结页使用“请选择要获得的连结印记”和属性徽记；遗物页不运行连结属性识别，避免把遗物图标误判为火/暗/光/风/水。

具体遗物识别由 `LabyrinthRelicRecognizer` 等流程完成，推荐由 `LabyrinthRelicChoicePolicy` 与已保存策略决定；页级指令命中不能单独证明遗物身份可靠或已经选取成功。只读模式不点击；桌面自动执行要求实际截图为 1920×1080 横屏，真实遗物场景仍需实机验收。
