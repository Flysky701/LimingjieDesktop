# 获得道具界面模板

2026-10-26 按当前共享页面识别与 `LabyrinthEntryActionPlanner` 核对。Android 与桌面复用本目录模板；它只描述弹窗识别和关闭，不负责评价或选择奖励。

用于识别连结节点的属性角色印记三选一完成后出现的“获得道具”弹窗。

- `item_reward_title.png`：弹窗标题“获得道具”
- `item_reward_instruction.png`：弹窗说明“获得了以下道具。”
- `item_reward_close.png`：底部“关闭”按钮

本组「获得道具」弹窗使用标题、说明和关闭按钮联合确认。当前 `ITEM_REWARD` 分类还包含其他目录的「迷宫遗物效果」和「遗物效果结果」标题/关闭锚点分支，不能将这三个文件视为该状态的唯一来源。自动化模式在页面稳定且动作条件允许时关闭弹窗，识别模式不会点击。

动作入口为 `CLOSE_ITEM_REWARD`，是否继续仍由会话的稳定页面与动作状态控制；派发关闭不等于游戏已完成关闭。桌面真实奖励流程仍需实机验收，自动执行要求实际截图为 1920×1080 横屏。
