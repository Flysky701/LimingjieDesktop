## 追加审计：国服攻略对“模型高分 / 玩家评价低”的解释

### 嘉夜（普通 / 六星）

- 玩家侧结论：六星后基本没有上场机会，主要原因不是“完全不能打”，而是开服角色机制和数值已经明显落后，同赛道有大量更强替代。
- 对模型的含义：这是典型的**相对竞争力**问题。单看角色自身面板和技能倍率，可能仍能得到一个不低的绝对输出值；但在实际选人时，应比较她与当前角色池同定位角色的边际差距。
- 不建议直接把这种攻略结论折算成角色固定减分。黎明界是随机角色池，如果当局没有更强同定位角色，旧角色仍可能是可用解。

### 铃奈（万圣节）

- 玩家侧结论：攻略直接给出“不推荐抽”，但这更接近抽取价值结论，缺少足够明确的战斗性能解释。
- 对模型的含义：暂不能据此下调战斗模型；只记为“需要继续寻找实战定位或机制解释”的审计项。

### 杏奈（夏日）

- 玩家侧结论：传统法队可用前排；小技能会降低队友魔攻，导致早期很难配队，需要大量辅助补偿；开专前使用空间很小，开专后有少量会战最优解及自动刀作业。
- 对模型的含义：这里有明确的**队友负面效果**与**培养阶段差异**。当前辅助模型主要累计正向 Buff，必须补充“对友军的负面 Buff / 自伤式队伍代价”，否则会系统性高估这类角色。
- 黎明界应使用其实际强化模板对应技能版本，不能混用“开专前”和“开专后”攻略结论。

### 兰法（夏日）

- 玩家侧结论：PVE 魔法范围辅助输出，主要在多目标/伪多目标环境上场；生涯竞争中无论和物理多目标队还是其他体系相比都缺少优势。
- 对模型的含义：这是**目标数量条件 + 同赛道竞争力**问题。AOE 不能只转成一个统一分数；需要区分单目标、2目标、3+目标或伪多目标场景。
- 在黎明界 BOSS 单目标环境下，应明显降低其 AOE 价值；在多目标关卡才恢复对应价值。

### 绫音（探险家）

- 玩家侧结论：PVE 物理范围辅助输出，主要会战使用；当时物理多目标整体被法刀压制，后续物理多目标崛起时又由中后卫阵容主导，而她的站位/阵型不契合；仅在后续特定版本短暂高光。
- 对模型的含义：这里同时出现**目标数量、队伍体系强弱、站位/阵型兼容性、版本竞争力**四个因素。单角色的“AOE + 物辅”高分不足以说明她在具体五人队中的真实价值。

## 审计规则更新

今后“模型与攻略严重冲突”时，先判断冲突属于哪一类：

1. **模型解析错误**：条件分支被同时结算、状态层数未模拟、技能动作重复计入等。必须修模型。
2. **战斗条件依赖**：半血以下、多目标、叠层、特定队友、阵型、站位等。应进入场景模拟，不应简单固定减分。
3. **相对竞争力**：角色自身并非不能打，但同定位有更强替代。应在组队边际贡献阶段自然淘汰，而不是修改角色基础数值。
4. **抽取价值**：免费、钻石成本、寿命、未来卡池、是否刚需、图鉴、大师碎片等。只作攻略参考，不参与黎明界战斗评分。

国服攻略受日服未来视影响是客观存在的，因此攻略评分可以继续作为**外部验证集**，但不作为战斗分的监督标签。优先使用攻略作者对“为什么强/弱”的文字解释，而不是直接使用“推荐抽 / 不推荐抽”的最终结论。
# 黎明界角色评分差异审计

## 目的

本文件用于记录“数据库战斗模型评分”与“真实用户/攻略评价”明显不一致的角色，并区分：

1. **模型计算错误**：条件分支、层数、触发概率、目标范围、行动循环等被错误计算；
2. **战斗环境差异**：角色只在特定血量、目标数、阶段、队伍体系下强；
3. **评价口径差异**：抽取攻略包含获取成本、免费角色、寿命、替代品、未来卡池等非战斗因素；
4. **真实战斗强度差异**：模型即使修正机制后，仍明显高估/低估角色实际表现。

用户评分和抽取推荐度只作为**外部验证信号**，不直接进入物理输出、法术输出、辅助输出公式。

## 已确认案例

### 克萝依（冬日）

- 当前模型：物理输出 100；物辅约 53.8；物防降低 100。
- 用户提供的攻略信息：
  - 强度不算高；
  - 前期水物理体系不完善时有一定出场机会；
  - 基本可视为海忍的上位替代之一；
  - 有一定强度，但不刚需；
  - 寿命较短，性价比较低；
  - 附带大师碎片有额外价值。
- 审计结论：
  - **存在明确模型错误**：`水月 <33 / >=33 / >=66 / =99` 为互斥/条件档位，V1 可能同时累计多个档位的伤害、物攻 Buff、破防；
  - 同时存在**评价口径差异**：攻略的低推荐还受刚需性、寿命、抽取成本影响，不能直接反推她战斗能力很低。

### 流夏（新年）

- 当前模型：物理输出 100；用户综合评分约 36。
- 用户提供的攻略信息：活动免费角色，只需刷到 3 星。
- 审计结论：
  - **不能用抽取推荐度验证战斗强度**，因为免费角色不存在宝石抽取成本；
  - 同时存在明确模型风险：`剑之刻印 = 35` 才触发的强化伤害/Buff不应每次技能都结算；
  - 应修复刻印状态机后再判断真实强度。

### 嘉夜（时空旅行）

- 当前模型：物理输出高分（异常列表中接近/达到 100）。
- 用户提供的攻略信息：
  - 前卫单体物理输出；
  - 没有破防或队友 Buff；
  - 技能组尴尬；
  - 实际输出差强人意；
  - 无特殊机制价值；
  - 基本属于仓管。
- 审计结论：
  - 这是目前最有价值的**纯输出模型反例**之一；
  - 修复条件分支后若仍高分，需要重点核查技能伤害公式、技能命中次数、行动时长、UB频率、自Buff覆盖率与重复动作计数。

### 祈梨（新年）

- 用户提供的攻略信息：JJC角色；免费角色；无相关 PvE 抽取攻略。
- 审计结论：
  - 抽取攻略数据不足；
  - 免费身份会显著影响推荐度；
  - JJC定位与黎明界 PvE 价值可能完全不同；
  - 暂不作为输出模型强校准样本。

### 莫妮卡（咖啡厅）

- 用户提供的攻略信息：介绍即为仓管，不推荐抽取。
- 审计结论：
  - 属于高优先级模型反例；
  - 需核查模型是否把条件伤害、条件 Buff、分支动作或特殊技能常驻化；
  - 若机制解析无误仍高分，再进一步核查其在标准 PvE 环境中的真实伤害能力。

### 怜（万圣节）

- 用户提供的攻略信息：俗称鬼剑，中卫；对半血以下目标特化的 AOE 输出；场景特化明显，仅在会战少量场合出场。
- 审计结论：
  - 这是典型的**条件伤害被标准模型高估**案例；
  - 模型不应把“敌人半血以下”的强化效果按 100% 覆盖计算；
  - 应区分标准场景评分与条件场景上限评分。

### 妮诺（大江户）

- 用户提供的攻略信息：
  - 会战低阶段基本必有轴，但并非必要；
  - 三阶段以后出场率随版本下降；
  - 与其他刀伤害差距不大，借位竞争激烈；
  - 临近泳装池导致抽取推荐度进一步下降。
- 审计结论：
  - 这是典型的**战斗强度与抽取价值分离**案例；
  - 她在特定 PvE 阶段确实有实际战斗价值，因此低抽取推荐不能用来证明模型高估；
  - 需要把“强度/适用阶段”和“抽取性价比”彻底分成两套标签。

## 后续审计原则

优先检查以下两类角色：

1. **模型战斗分极高，但攻略明确表示实际输出低/仓管**：优先判断为模型公式或机制解析问题；
2. **模型战斗分高，但攻略只说不推荐抽/短命/有替代/免费**：优先判断为评价口径差异，不直接下调战斗模型。

建议后续为每个角色保留三个彼此独立的维度：

- `combatValue`：黎明界环境中的实际战斗价值；
- `scenarioDependence`：对血量、目标数量、层数、特定队伍、长短战斗等条件的依赖；
- `acquisitionValue`：抽取成本、免费与否、寿命、替代品、未来卡池等，只用于攻略参考，不参与自动配队。
