# 黎明界助手 1.0.18 产品测试更新说明

日期：2026-10-18　版本号：1.0.18（10018）　状态：测试版

## 本版更新

1. **修复商店未刷新就关闭的问题。** 本轮遗物已买完，或完整三个商品位均已不可购买/确认为职能印记时，优先按策略刷新。恢复任务后不再必须依赖本轮购买计数与已售罄商品的标题识别；刷新按钮尚未可靠识别时等待，不把识别缺失当作金币不足而退出。
2. **商店刷新遵循设置的起始区域。** 设置从第 4 区或更早开始刷新后，第 4 区也按设置购买与刷新。默认仍从第 5 区允许刷新；关闭购买或刷新时遵循对应开关。未确认的可购买商品仍不会盲买或直接跳过。
3. **合入渠道服登录适配。** 增加 vivo、九游登录 SDK 界面处理，并处理临时竖屏后的截图恢复；4399、应用宝、MuMu 的刷开局流程增加大退处理。节点点击和手势均经过任务会话与暂停校验，支持同框文字节点的可点击父节点。

## 建议重点测试

| 场景 | 操作与预期 |
| --- | --- |
| 遗物售罄后恢复任务 | 刷新按钮可用时继续刷新，不因丢失购买计数直接退出。 |
| 刷新按钮识别不稳定 | 等待稳定识别后再决定刷新或结束商店。 |
| 调整允许刷新起始区域 | 在指定区域及之后按设置刷新，特别核对第 4 区。 |
| 商品尚未识别完 | 等待识别，不把未确认的可购买遗物直接跳过。 |
| 渠道 SDK 登录与临时竖屏 | 核对目标条目点击、暂停时不点击，以及返回横屏后截图恢复。 |
| 渠道服批量刷开局 | 核对大退、回到客户端后的画面检查及失败提示。 |
